# rclone-personal

rclone-personal is a private tool used only by its owner (lunasnow1231) to mount the owner's own Google Drive on the owner's own Linux PC with rclone.

rclone-personal は、持ち主（lunasnow1231）が自分の Google ドライブを自分の Linux PC に rclone でつなぐためだけに使う個人用ツールです。

## Privacy Policy / プライバシーポリシー

This tool is not offered to anyone else. Google Drive data is transferred only between Google and the owner's PC. No data is collected, stored on any other server, shared with third parties, or used for advertising.

このツールは他の人には提供していません。Google ドライブのデータは Google と持ち主の PC の間でだけやり取りし、収集・他のサーバーへの保存・第三者への提供・広告への利用は一切しません。
